# 🐍 贪吃蛇游戏

经典网页版贪吃蛇小游戏，原生前端实现，无任何第三方依赖。

## ✨ 功能特点
- 方向键控制蛇的移动
- 吃到食物自动增长长度并加分
- 实时更新分数，记录最高分
- 撞墙/撞到自己身体游戏结束
- 支持按空格键重新开始

## 🎮 操作说明
- 上/下/左/右方向键：控制蛇的移动方向
- 空格键：游戏结束后重新开始

## 🛠️ 技术实现
- HTML：页面结构搭建
- CSS：基础样式与游戏区域美化
- JavaScript：游戏逻辑实现（蛇的移动、碰撞检测、分数计算等）
