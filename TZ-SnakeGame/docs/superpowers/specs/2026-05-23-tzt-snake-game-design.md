# TZT贪吃的蛇 — 设计文档

## 概述

一个像素治愈风格的贪吃蛇网页游戏，单 HTML 文件实现，零外部依赖，双击即可打开。

## 技术选型

| 维度 | 选择 | 理由 |
|------|------|------|
| 项目结构 | 单 HTML 文件 | 零依赖，部署最简单 |
| 渲染 | Canvas 2D | 像素风格绘制，性能好 |
| 音频 | Web Audio API | 无需外部音频文件 |
| 存储 | localStorage | 持久化最高分和主题设置 |
| 架构 | 模块化分区 + 状态机 | 代码清晰，状态转换可控 |

## 状态机

```
MENU ──开始──→ PLAYING ──死亡──→ GAME_OVER
  ↑               ↑                │
  │               │ 重新开始        │
  │               └────────────────┘
  └────────返回主菜单──────────────┘
```

### MENU 状态
- **enter()**: 播放轻柔 BGM，显示主菜单 UI
- **update()**: 监听按钮点击
- **render()**: Canvas 绘制像素粒子背景动画

### PLAYING 状态
- **enter()**: 隐藏菜单 UI，初始化蛇/食物，加载当前主题
- **update()**: 游戏逻辑 tick（移动、碰撞检测、吃食物）
- **render()**: 绘制网格、蛇身、食物、得分

### GAME_OVER 状态
- **enter()**: 切换忧郁音乐，显示雨滴粒子，显示抑郁文案和按钮
- **update()**: 监听按钮点击
- **render()**: 暗色遮罩 + 雨滴动画

## 核心数据结构

```js
gameState = {
  snake: [{x, y}, ...],       // 蛇身坐标数组，head 在 [0]
  direction: {x, y},          // 当前方向
  nextDirection: {x, y},      // 下一帧方向（防止反向）
  food: {x, y},               // 食物位置
  score: 0,                   // 当前得分
  highScore: localStorage,    // 最高分（持久化）
  speed: 150,                 // ms/tick，随得分递增
  currentState: 'MENU',       // 当前状态
  theme: { snake, bg, grid, food }  // 当前主题配置
}
```

## 画布规格

- 逻辑分辨率：400×400 像素（20×20 格子，每格 20px）
- 实际显示：CSS 自适应缩放，保持正方形，居中
- 响应式：移动端适配屏幕宽度，PC 端固定最大尺寸

## 渲染层级

```
① 背景色填充
② 网格线/点阵
③ 食物（带呼吸式发光）
④ 蛇身（head 亮色 + 眼睛，body 渐变暗）
⑤ 得分弹出动画
⑥ 失败时：暗色遮罩 + 雨滴粒子
```

## 像素风格细节

- 蛇身：每节是带 1px 边框的圆角矩形，head 有小眼睛
- 食物：呼吸式发光（shadow pulse），每 800ms 明暗交替
- 移动：每 tick 跳一格（非连续滑动），强调像素感
- 帧率：渲染用 requestAnimationFrame（60fps），逻辑用 setInterval 按速度 tick

## 操作方式

- PC：WASD / 方向键
- 移动端：触摸滑动（检测滑动方向）
- 防止反向移动（蛇不能直接掉头）

## 得分系统

- 吃到食物：+1 分，屏幕短暂闪白 + 分数弹出动画 + 音效
- 每 10 分：速度小幅提升（150ms → 140ms → ... 最低 80ms）
- 最高分：localStorage 持久化

## 音频引擎（AudioEngine）

### 音乐

| 场景 | 风格 | 实现 |
|------|------|------|
| 主菜单 & 游戏中 | 轻柔舒缓电子乐 | 合成器 pad 和弦 + 简单琶音循环，BPM 70-80 |
| 游戏失败 | 轻微忧郁 | 降低音调，加入混响，节奏变慢，和弦转小调 |

### 音效

| 事件 | 音效 | 实现 |
|------|------|------|
| 吃到食物 | 短促上升音阶 | 3-4 个音符快速上行，正弦波 |
| 得分里程碑(10/20/30) | 华丽音阶 | 更多音符 + 轻微延迟回声 |
| 撞墙/死亡 | 低沉 "咚" | 低频方波 + 快速衰减 |
| 按钮点击 | 轻柔点击声 | 短脉冲白噪音 |

### 音乐过渡

- 失败时：当前音乐 1s 淡出，忧郁音乐 0.5s 后淡入
- 回到菜单：忧郁音乐淡出，BGM 淡入
- 实现：两个独立 OscillatorNode 组，通过 gain ramp 平滑过渡

## 外观系统（ThemeManager）

### 可自定义维度

**蛇身颜色（6 种）：**
- 经典绿：head #6ba368, body #4a7c59
- 霓虹粉：head #ff6b9d, body #e84580
- 冰蓝：head #6bc5f0, body #4a9dc5
- 暗夜紫：head #a855f7, body #7c3aed
- 琥珀金：head #f59e0b, body #d97706
- 珊瑚橙：head #fb923c, body #ea580c

**背景色（6 种）：**
- 深海 #0f172a, 森林 #0f1a0f, 沙漠 #1a1510
- 樱花 #1a0f15, 极简白 #f5f5f5, 深空 #0a0a14

**网格样式（4 种）：**
- 隐约：半透明细线
- 清晰：明显网格线
- 无网格：纯色背景
- 点阵：圆点阵列

**食物样式（4 种）：**
- 经典苹果：红色方块 + 发光
- 星星：金色星形 + 发光
- 蓝莓：蓝色圆形
- 钻石：紫色菱形 + 发光

### 切换动画

- 选择新主题后，颜色 300ms 线性插值过渡
- Canvas 中逐帧插值实现平滑渐变

### 持久化

- 主题配置保存在 localStorage
- 下次打开自动恢复上次选择

### 主题生效时机

- 点击"开始"（主菜单）→ 生效
- 点击"重新开始"（失败画面）→ 生效
- 点击"主菜单"（失败画面）→ 不生效

## 游戏失败画面

### 视觉效果

- 暗色遮罩：透明度从 0 渐变到 0.6（500ms）
- 雨滴粒子：50-80 个半透明蓝色线条从顶部下落，速度和长度随机
- 蛇身变灰：死亡后 300ms 内去饱和度，变为灰色调

### 抑郁文案库

30+ 条预写中文文案，按得分区间变化：

- **低分（<10）**：自嘲型
  - "这么快就放弃了？和你的人生一样。"
  - "连两位数都没到，你真的很稳定——稳定地失败。"

- **中分（10-30）**：哲学型
  - "越努力越长，越长越容易绊倒自己。"
  - "每一口食物都填补不了内心的空虚，就像每一次得分都治愈不了深夜的孤独。"

- **高分（>30）**：深沉型
  - "你已经很努力了，但有些墙是注定要撞的。"
  - "最高纪录是 42，但孤独的纪录是永远。"

### 按钮

- "重新开始"：进入 PLAYING，应用当前主题
- "主菜单"：回到 MENU，不切换主题

## UI 布局

### 主菜单
- 标题 "TZT贪吃的蛇" + 副标题
- "开始游戏"按钮（主色调，显眼）
- "外观设置"按钮（次色调）
- 最高纪录显示
- 背景：缓慢飘动的像素粒子

### 游戏中
- 顶部：当前得分（大字）+ 最高纪录（小字）
- 中间：游戏画布
- 底部：操作提示（PC: WASD/方向键，移动端: 滑动）

### 外观设置面板
- 弹出式面板，覆盖在主菜单上
- 四个分区：蛇身颜色、背景色、网格样式、食物样式
- 每个选项用缩略预览展示
- 点击即应用，返回主菜单

### 游戏失败
- 全屏暗色叠加
- 居中：Game Over + 得分 + 最高纪录
- 抑郁文案（斜体，居中）
- 两个按钮：重新开始 / 主菜单
